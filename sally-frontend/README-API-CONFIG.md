# راهنمای تنظیم API برای فرانت‌اند

## نحوه استفاده از اسکریپت‌های توسعه

### 1. توسعه محلی (پیش‌فرض)
برای اجرای فرانت‌اند با اتصال به بک‌اند محلی:

```bash
npm run start-dev
```

### 2. اتصال به سرور اصلی
برای اجرای فرانت‌اند با اتصال به سرور اصلی:

```bash
API_TARGET=192.168.10.221:8000 npm run start-dev
```

### 3. استفاده از روش سنتی
اگر ترجیح می‌دهید از روش سنتی استفاده کنید:

```bash
# برای توسعه محلی
npm start

# برای اتصال به سرور اصلی
# ابتدا فایل setupProxy.js را تغییر دهید:
# target: 'http://localhost:8000' را به target: 'http://192.168.10.221:8000' تغییر دهید
npm start
```

## تنظیمات فعلی

### API Endpoints
- **Main API**: `http://localhost:8000` (پیش‌فرض) یا `http://192.168.10.221:8000` (سرور اصلی)
- **Whisper API**: `http://192.168.10.222:8001`
- **Vosk API**: `http://192.168.10.222:8002`

### فایل‌های تنظیمات
- `setupProxy.js`: تنظیمات proxy برای توسعه
- `package.json`: تنظیمات proxy برای تولید
- `scripts/start-dev.js`: اسکریپت هوشمند برای راه‌اندازی

## نکات مهم

1. **تغییر سریع**: با استفاده از متغیر محیطی `API_TARGET` می‌توانید به سرعت بین حالت‌های مختلف سوئیچ کنید.

2. **CORS**: تنظیمات CORS به صورت خودکار توسط proxy مدیریت می‌شود.

3. **Whisper و Vosk**: این سرویس‌ها روی سرور جداگانه‌ای اجرا می‌شوند و نیازی به تغییر ندارند.

4. **پورت‌ها**:
   - فرانت‌اند: 3000
   - بک‌اند اصلی: 8000
   - Whisper: 8001
   - Vosk: 8002

## عیب‌یابی

### اگر با خطای CORS مواجه شدید
1. مطمئن شوید بک‌اند در حال اجراست
2. تنظیمات proxy را بررسی کنید
3. از اسکریپت `start-dev` استفاده کنید

### اگر اتصال برقرار نشد
1. آدرس IP را بررسی کنید
2. فایروال را بررسی کنید
3. پورت‌ها را بررسی کنید
